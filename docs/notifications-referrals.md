COCONUT X

Notifications and Referral System

Version 1.0 - MVP

1. Purpose

The notification and referral system helps users stay informed, return to the platform and invite friends.

2. Notification Types

The platform should support:

- New challenge notifications
- Challenge participation updates
- Submission status updates
- Voting results
- Ranking changes
- Achievement notifications
- Invitation notifications
- Important account notifications

3. Notification Center

Users should be able to:

- View notifications
- Mark notifications as read
- Mark all notifications as read
- Open the related challenge or submission
- View notification history

4. Notification Preferences

Users should be able to control optional notifications.

Important security and account notifications must remain available.

5. Delivery Methods

Initial delivery methods:

- In-app notifications
- Telegram notifications where permitted

Future options:

- Web push notifications
- Mobile push notifications

6. Referral System

Every user can receive a unique referral code.

Users should be able to:

- Copy their referral link
- Share their referral link
- Invite friends
- View successful invitations

7. Referral Tracking

The backend must:

- Generate unique referral codes
- Validate referral links
- Track successful registrations
- Prevent duplicate referral rewards
- Detect suspicious invitation activity

8. Referral Abuse Prevention

- Prevent self-referrals.
- Prevent duplicate referral claims.
- Apply rate limits.
- Detect automated registrations.
- Never reward fake accounts.
- Keep referral records auditable.

9. Referral Rewards

The MVP should use non-monetary engagement features only.

Possible future features:

- Profile badges
- Participation achievements
- Referral milestones

No cash rewards or paid referral schemes in the MVP.

10. Database Requirements

The system should support:

- User notifications
- Notification read status
- Notification creation timestamps
- Referral codes
- Inviter identification
- Successful referral records

11. Interface Design

Follow the COCONUT X visual identity:

- Background: #10101C
- Neon pink: #FF63B5
- Turquoise: #54E7F0
- Purple: #A78BFA
- Soft orange: #FFAD82

The interface must remain simple, responsive and mobile-friendly.

12. Privacy

- Do not expose private user information.
- Do not send unwanted promotional notifications.
- Respect notification preferences.
- Protect referral records.

13. MVP Success Metrics

Measure real platform data:

- Number of notifications delivered
- Notification read rate
- Referral link visits
- Successful invited registrations
- Active users returning to the platform

Never display fabricated statistics.
