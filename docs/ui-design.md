COCONUT X

UI/UX Design Specification

Version 1.0 - MVP

1. Design Vision

Create a premium, modern, simple and engaging global social challenge platform.

The interface must be visually memorable, easy to use and optimized for user engagement and organic growth.

2. Visual Identity

- Midnight background: #10101C
- Neon pink: #FF63B5
- Turquoise: #54E7F0
- Purple: #A78BFA
- Soft orange: #FFAD82
- Main text: #F5F5FA
- Secondary text: #A7A7BA

Use dark surfaces, subtle gradients, clean typography and controlled neon highlights.

Avoid excessive visual effects and clutter.

3. Main Navigation

Mobile navigation:

- Home
- Discover
- Create Challenge
- Rankings
- Profile

The Create Challenge action should be visually prominent.

4. Home Screen

The home screen should contain:

- COCONUT X brand identity
- Welcome section
- Featured challenges
- Trending challenges
- New challenges
- Daily challenge
- Global leaderboard preview
- Clear Create Challenge action

Challenge cards should display:

- Challenge title
- Category
- Cover image
- Participation count
- Remaining time when applicable
- Join button

Only real platform data may be displayed.

5. Discover Screen

Users can:

- Browse challenges
- Search by title
- Filter by category
- Sort by popularity
- Sort by newest
- Find active challenges

6. Challenge Details

Each challenge page should display:

- Title and description
- Creator information
- Rules
- Category
- Deadline
- Number of participants
- Submissions
- Voting information
- Join Challenge button

7. Create Challenge Screen

Use a simple creation form:

- Challenge title
- Description
- Category
- Rules
- Participation deadline
- Optional cover image

Provide clear validation and confirmation messages.

8. Rankings Screen

Display:

- Global leaderboard
- Category rankings
- Challenge rankings
- User scores and positions

Ranking rules must be transparent.

9. Profile Screen

Display:

- Profile picture
- Username
- Biography
- Total participation
- Completed challenges
- Ranking
- Submission history

10. User Growth and Engagement

Include:

- Daily challenges
- Shareable challenge links
- Invite friends
- Achievement badges
- Participation milestones
- Leaderboard updates

Never use fake user counts, fake activity or misleading popularity indicators.

11. Languages

Initial languages:

- Persian
- English

Support right-to-left Persian and left-to-right English layouts.

The architecture must allow additional languages.

12. Responsive Design

Mobile-first design is mandatory.

The interface must adapt to:

- Android phones
- iPhones
- Tablets
- Desktop browsers

13. Accessibility and Usability

- Readable text
- Clear buttons
- Adequate contrast
- Simple navigation
- Loading states
- Empty states
- Error messages
- Confirmation before destructive actions

14. Motion and Effects

Use subtle animations for:

- Page transitions
- Button interactions
- Loading indicators
- Voting feedback
- Ranking changes

Animations must not reduce performance.

15. Performance

- Optimize images
- Minimize unnecessary requests
- Load content efficiently
- Avoid heavy visual effects
- Keep mobile performance a priority

16. Design Principles

1. Simple before complicated.
2. Fast before flashy.
3. Clear before decorative.
4. Trustworthy before attention-seeking.
5. Original visual identity.
6. Consistent experience across languages and devices.
